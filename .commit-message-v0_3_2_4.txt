Two one-line fixes surfaced during v0.3.2.3 adversarial-loop A/B prep.

- Default model: claude-sonnet-4-20250514 → claude-sonnet-4-6.

  Sonnet 4, May 2025). Every deck produced v0.2.0–v0.3.2.3 ran on
  year-old model.

  stage_adversarial_review. The actual installed binary (per
  beril-adversarial pyproject [project.scripts]) is `beril-adversarial`.

  Adam's earlier setup but blocked fresh installs (live failure
  during v0.3.2.3 adversarial A/B). Updated install-hint message
  to reference beril-adversarial v0.5.1 (sibling release with same
  model bump).

No new tests required. 496/496 unit tests still pass.
