v0.3.0: adversarial review-rewrite loop + image-gen calibrated

Two-stream feature release. Stream A wires beril-adversarial
--type presentation (shipped in beril-adversarial v0.4.0) into a
review-rewrite loop. Stream B calibrates the CBORG image-gen
client (gemini-3-pro-image) and encodes calibration verdicts into
the ai_image_prompt.v1 prompt defaults.

Stream A — adversarial review-rewrite loop

- prompts/revise_slide.v1.md: per-finding-class subagent for
  register_drift / claim_evidence / qa_softball / substory_arc /
  narrative_weakness. Preserves slide id/position/substory_id;
  appends to revision_log.
- prompts/add_slide.v1.md: handler for missing_slide findings.
  Layout-selection table; HARD-CAPS claim_evidence bullets at 1-3
  (validator-blocking).
- tools/revise_loop.py (~570 LOC): driver dispatches each P0/P1
  finding via claude -p; validates after each finding; per-finding
  rollback via copy.deepcopy snapshot. Cost + revision caps.
- Orchestrator stages 12 + 13 in presentation_maker.sh
  (stage_adversarial_review + stage_revise_slides). New flags
  --no-adversarial / --max-revise-cost-usd / --max-revisions.
- continue_run.py _VALID_STAGES extended.

Live test draft_10: F001 (register drift on slide 8) + F003 (top-N
candidates new slide) landed cleanly for ~$0.73 total.

Stream B — image-gen calibrated

- tools/image_gen_calibration.py (~600 LOC): live test harness
  (T0 smoke + T1 brand_color + T2 style_baseline + T3 text + T4
  slide2). Cost cap; halts on budget. Run 2026-04-30: 13/13 ok,
  $0.177.
- tools/image_client.py: DEFAULT_MODEL changed to gemini-3-pro-
  image (CBORG drops provider prefix). Error messages surface
  payload + response body. Rate-card table extended.
- prompts/ai_image_prompt.v1.md updated with calibration defaults:
  default style scientific_illustration (T2 winner); default
  palette KBase hex #007DC3/#5E9732/#F78E1E (T1 winner); in-image
  text permitted when named (T3 verdict); genome-ring composition
  named as preferred opener for fraction-unknown claims (T4
  winner). Style enum extended.
