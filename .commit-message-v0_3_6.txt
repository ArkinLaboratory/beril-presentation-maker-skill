v0.3.6: halt-and-handoff at the throughline-pick gate (paper-writer pattern)

Closes the architectural bug surfaced on the KBERDL JupyterHub on
2026-05-05: presentation-maker's `gate_throughline_pick` used
`read -r pick </dev/tty`, which fails 100% of the time when Claude
Code auto-backgrounds bash on the hub. Every hub participant who
runs `/beril-presentation-maker` would hit this gate and the
pipeline would error out at exit code 1 after stages 1-2 had
already paid $2-3 in LLM cost.

This commit ports paper-writer's halt-and-handoff pattern at the
one gate that matters. v0.4.0 (post-event) replaces the
single-purpose handoff with a full state.json + Phase enum and
migrates the substory_overflow gate too; v0.3.6 ships the minimal
fix that unblocks Thursday's event.

Behavior change

  Before (v0.3.5.x):
    user runs `beril-presentation-maker draft <project_id>`
    bash runs stages 1-2
    bash blocks at `read -r pick </dev/tty` waiting for human input
    if no TTY: read fails, pick is empty, parser rejects, bash exits 1
    if TTY: human types TL1/TL2/..., bash continues to .pptx

  After (v0.3.6):
    user runs `beril-presentation-maker draft <project_id>`
    bash runs stages 1-2
    bash writes <draft_dir>/.handoff.json (phase=throughline_pick +
                                            candidates + candidates_md path)
    bash prints "halt: pick a candidate, run `continue --pick TLN`"
    bash exits 0 (clean halt, NOT failure)
    user/agent reads handoff, picks, runs `continue --pick TLN`
    continue validates pick against candidates, writes 00_throughline.md,
      removes .handoff.json, dispatches bash with --resume-from substory_design
    bash runs stages 3-14 to .pptx

  --auto-advance unchanged: still auto-picks TL1 and runs end-to-end
  without halting. CI/unattended scripts using --auto-advance keep
  working without modification.

  --resume-from <stage> unchanged: still works as the legacy power-user
  stage-replay mode. Mutually exclusive with --pick (errors if both are
  passed). Used for prompt iteration / failure recovery.
