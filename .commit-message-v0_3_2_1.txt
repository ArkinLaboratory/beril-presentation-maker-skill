v0.3.2.1: hotfix — figure resolver, prompt teaching, position population

Closes four bugs surfaced by the v0.3.2 live smoke on
core_gene_tradeoffs. The smoke completed (25 slides, deck rendered)
but three figure assets failed to render, no data_table layout was
ever picked, and the slide_spec lacked position fields. None of
these were caught by unit tests because they only manifest in the
end-to-end flow with a real BERDL project.

Bugs fixed

- Figure resolver broken under v0.3.1 layout. _derive_project_dir
  walked draft_dir → talks → project_dir, but in v0.3.1 the
  assembler's draft_dir = slide_spec_path.parent = draft_N/working/,
  not draft_N/. New _derive_actual_draft_dir helper strips a
  trailing working/ segment; _derive_project_dir extended to walk
  3 levels up from working/. Both legacy (v0.3.0) and v0.3.1+
  layouts work.

- figures_curated.md duplicate not fully killed. v0.3.1 removed the
  orchestrator's cp workaround but curate_figures.py still wrote
  the legacy name. curate_figures.py now writes curated_figures.md
  directly.

- merge_compose_fragments.py did not populate position. ALL 25
  slides in the smoke had position=None. Stream A's
  _insert_slide_into_spec then ran the A1 fallback chain on every
  revision. merge_compose_fragments.py now sets
  slide["position"] = array_index + 1 on every merged slide.

- slide_compose.v1.md did not know about data_table. v0.3.2 added
  schema + handler + add_slide.v1.md mention but missed the
  primary slide-composing prompt. slide_compose.v1.md now teaches
  data_table: layout-diversity menu entry with "strongly preferred
  over data_figure when figure is a table-shaped image" guidance;
  full per-layout schema section; two worked examples (top-N rank +
  quadrant matrix); 16-layout vocabulary callout.

Tests

- 5 new tests in test_assemble_pptx.py covering _derive_actual_draft_dir
  (v0.3.1 / legacy), _derive_project_dir (v0.3.1 / legacy),
  _resolve_asset_path end-to-end against project_dir/figures/X.png
  from a v0.3.1-shaped working/ dir.
- test_cli_curate_subcommand_writes_outputs: updated to verify
  canonical name is written + legacy name is NOT.
- test_merge_writes_valid_slide_spec: updated to verify positions
  are populated 1-based.
- 488/488 unit tests pass (was 483 in v0.3.2).
