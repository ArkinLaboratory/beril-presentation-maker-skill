v0.2.0: first install-shippable release

The fourth skill in the BERIL drop-in quartet (atlas, adversarial,
paper-writer, presentation-maker) reaches install-shippable parity.
The 11-stage drafting pipeline that grew under earlier `v0.1.x-*` and
`v0.2.x-pipeline` tags now ships behind a real CLI: pipx-installable,
deployable into a BERIL checkout via install-skill, invocable through
slash commands.

CLI plumbing (Tier A — ports paper-writer pattern):
- src/beril_presentation_maker/cli.py: rewrite from stub-dispatching to
  real subparser dispatch (mirrors paper-writer / adversarial pattern).
- src/beril_presentation_maker/commands/install_skill.py: NEW. Copies
  shipped skill/ tree into <BERIL>/.claude/skills/beril-presentation-maker/.
  Preserves install-local state/. Sets exec bits on tools/*.sh + .py.
- src/beril_presentation_maker/commands/configure.py: NEW. Hard checks
  for claude CLI + python-pptx + nbformat + Pillow; soft checks for
  beril-adversarial-cli + LibreOffice + mermaid-cli + bash + POSIX core.
- src/beril_presentation_maker/commands/draft.py: NEW. Thin wrapper
  around presentation_maker.sh forwarding flags.
- src/beril_presentation_maker/commands/continue_run.py: NEW. Thin
  wrapper around presentation_maker.sh --resume-from <stage>.
- src/beril_presentation_maker/commands/assemble.py: NEW. Direct Python
  invocation of assemble_pptx.assemble() with optional LibreOffice PDF
  render.
- src/beril_presentation_maker/discovery.py: real implementation
  (was NotImplementedError stub). Vendored from paper-writer with
  SKILL_DIR_NAME="beril-presentation-maker".
- src/beril_presentation_maker/state.py: real read/write helpers.
  Orchestrator is canonical for state semantics in v0.2.0.
- src/beril_presentation_maker/__init__.py: __version__ = "0.2.0".
