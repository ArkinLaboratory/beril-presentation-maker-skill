v0.2.2: visual-review patch from draft_10

Second post-ship patch. v0.2.1 closed most master-template issues
but draft_10 visual review surfaced 6 remaining layout problems plus
1 design-intent rethink (big_idea). All address the visual quality
gap between v0.2.1's deck and a presentable scientific talk.

Master fixes (build_master.py LAYOUT_FIXES):

- qa_anticipated: title H 1.00 → 1.30 in (slide 23's 5-line question
  bled past v0.2.1's 1.00 in placeholder, causing title-body
  vertical collision). Body T 1.30 → 1.55 (clear taller title). Body
  H 4.00 → 3.75 (maintain logo clearance). 2-line normAutofit
  belt-and-suspenders at layout level.

Assemble fixes (assemble_pptx.py):

- big_idea: dual-mode handler. Default render is centered-assertion
  (no banner, title at slide-center, 48pt, normAutofit). Banner +
  image mode lights up only when supporting_graphic is present —
  forward-compatible with v0.3's ai_image_prompt.v1 so generated
  graphics will trigger the banner+image rendering automatically.
  Live failure: draft_10 slide 2 was title-at-top + empty body
  because LLM rarely emits supporting_graphic.

- qa_anticipated: _enable_normautofit fontScale 80% → 60% specifically
  for qa_anticipated. Math: 60% × 18pt × 1.2 leading × 9.32 in ×
  3.75 in ≈ 2000-char capacity, fits worst-case 2KB answers.
  methods/refs stay at 80% (their content fits within that).

- workflow_diagram: step_caption textboxes now use word_wrap=True
  (v0.2.1 missed). Live failure: draft_10 slide 9 step captions
  rendering as overlong single lines bleeding across 3-column
  layout.

- two_column_compare: _enable_normautofit calls added for both
  column placeholders (idx 1, idx 2). Live failure: draft_10 slide
  19 right column "scores 0.875 for CRISPRi analysis" running into
  bottom logos.

- claim_evidence figure_caption: drop auto_size=True (was overriding
  word_wrap in python-pptx). Geometry: FIGURE_REGIONS["claim_evidence"]
  H 3.50 → 3.15 to clear 0.40 in band for caption above logos.
  Live failure: draft_10 slide 18 caption "across cond..." truncated.

- acknowledgments: TBD soft-default. When contributors list contains
  "TBD - populated by production orchestrator" or similar, replace
  with "Acknowledgments to be added before presentation." Live
  failure: draft_10 slide 25 rendering with literal "TBD" bullets.

New helpers in assemble_pptx.py:

- _remove_decorative_banner(slide) — finds and removes the first
  non-placeholder shape in the spTree (used by big_idea Mode 1)
- _reposition_placeholder_to_center(slide, idx, ...) — runtime
  override of layout-defined placeholder geometry
- _set_title_font_size(slide, font_pt) — sets run-level font size
  on the title placeholder
- _enable_normautofit_on_title(slide) — wrapper for title autofit
- _is_tbd_placeholder(text) — recognizes TBD-style placeholders
